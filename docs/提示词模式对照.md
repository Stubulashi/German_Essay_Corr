# 提示词模式对照(全模式重构 · 2026-09-18)

> 范围:系统全部**系统提示词与用户消息模板**(不含后端确定性渲染的报告模板)。
> 验证:`backend/tests/test_prompt_modes.py`(22 用例:契约恒等 / 模式差异化 / 边界覆盖 / 注入兼容 / 用户消息)。

## 一、模式清单

| 模式 | 接管角色 | 构建入口 | 输出契约 |
|---|---|---|---|
| 管线 A 综合批改 | 看图一手批改者 | `build_pipeline_a_prompt(standard, detail, style, appendix)` | `_GRADING_JSON_SPEC`(锁定) |
| 管线 B 识别(OCR) | 纯转录官 | `build_ocr_prompt(appendix)` | 三字段契约(锁定) |
| 管线 B 评分 | 只依据给定转录的评卷人 | `build_grading_prompt(standard, detail, style, appendix)` | `_GRADING_JSON_SPEC`(锁定) |
| 考试识别 | 阅卷机器 | `build_exam_ocr_prompt()` | 逐题契约(锁定) |
| 示范学习归纳 | 批改风格归纳师 | `STYLE_SUMMARY_SYSTEM_PROMPT`(style_learning_service) | 四维契约(锁定) |

用户消息模板(集中于 `app/pipelines/prompts.py`):
`build_pipeline_a_user_message(page_count)` / `build_ocr_user_message(page_count)` /
`build_grading_user_message(...)`(签名不变) / `build_exam_user_message()`。

## 二、六区块架构(每份系统提示词统一)

1. 【身份与使命】每模式独立成段,不共享句式;
2. 【工作流程】编号步骤,模式专属;
3. 【本模式规则】评分标准区(GAOKAO/DSD)+ 细致度区(LOW/MEDIUM/HIGH),整段独立文本;
4. 【边界情况处理】模式专属清单;
5. 【输出前自检】模式专属防漂移清单(纯 JSON / 字段齐 / 枚举封闭 / 格式 / 片段可核);
6. 【输出契约】共享常量,逐字节不变。

注入层(顺序不变):示范学习风格(`STYLE_CONTEXT_HEADER`)→ 教师自定义附录(`APPENDIX_HEADER`)。

## 三、模式差异对比矩阵

| 维度 | A 综合批改 | B 识别 | B 评分 | 考试识别 | 风格归纳 |
|---|---|---|---|---|---|
| 身份定位 | 看图一手批改者(识别+评分一体) | 纯转录官(零评判零修正) | 只依据给定转录的评卷人 | 阅卷机器(只读数不评价) | 批改风格归纳师(不重新判分) |
| 输入依赖 | 原始图片 | 原始图片 | 仅转录文本(可能含人工校对) | 考卷/答题卡图片 | 一份已完成批改结果 |
| 核心流程 | 定位信息栏→按页序通读→图**文核对**→评分 | 页序清点→逐页转录→通读核对 | **转录体检**(完整性/占位符/OCR 噪声)→精读→评分 | 卷面定位→板块扫描→听力主动剔除→逐题登记→**总分自校验** | 通读观察→四维提取(证据引用)→narrative |
| 评分/产出轴 | 见标准区 | 仅转录文本 | 见标准区 | 逐题得分+总分 | 四维画像+narrative |
| 错误片段约束 | 图上可核 | — | 逐字取自给定转录 | — | 证据可溯源 |
| 边界重点 | 多页拼接/涂改/非德语/空白页 | `[unleserlich×n]`/`[leer]`/`[nicht-deutsch]`/`[Seitenreihenfolge prüfen]` | 截断/乱码占位不扣分/缺姓名不推断 | 0.5 步长/涂改判错/题号推断标注/无法辨认填 null | 信息不全注明"依据有限"/矛盾以修改行为为主 |

## 四、评分标准区差异(标准整段独立)

| 维度 | GAOKAO | DSD / CEFR |
|---|---|---|
| 评分轴 | 语言准确性为主轴(扣分制) | 交际成效与篇章能力为主轴(语法错误=限制等级的证据) |
| 分数格式 | `"18 / 25"` 固定形制 | 结论式等级:`"B1 Pass"`、`"A2 / B1 之间"`(不新增变体) |
| 防漂移手段 | 四档分数锚点(24-25 / 20-23 / 15-19 / <15) | 四维观察(任务完成/连贯/词汇/结构)+ 等级依据必须引用具体表现 |
| 评语要求 | 内容切题与结构点评但不参与扣分 | 等级依据 2~3 处引用;区间模糊给区间结论+改进点 |

## 五、细致度区差异与字段填充矩阵

| 字段 | LOW(红线原则) | MEDIUM(均衡覆盖) | HIGH(保姆级解析) |
|---|---|---|---|
| 记录范围 | 仅最显著错误,≤15 条 | 全覆盖语法用词,明显标点大小写 | 全覆盖(含标点/大小写),重复合并计数 |
| `original_text` | 必填 | 必填(含上下文) | 必填 |
| `corrected_text` | 允许 `""` | 必填且非空(可直接替换) | 必填且非空(可含更地道表达) |
| `error_type` | 必填(枚举) | 必填(枚举) | 必填(枚举) |
| `explanation` | 必须 `null` | 必须 `null` | 必填:规则名+单步推理+例句 |
| 渲染器消费 | 仅显示原句 | 显示修正 | 显示修正+解析 |

(字段矩阵与 `report_renderer` 的 LOW/MEDIUM/HIGH 展示逻辑严格对齐。)

## 六、稳健性与兼容性

- 稳健性:每模式【输出前自检】+ 通用防漂移句("无法确定宁可保守少标,严禁编造");考试模式新增**总分自校验**;枚举去重为 `_ERROR_TYPE_CHOICES`(文案与旧版逐字一致);
- 兼容红线:`_GRADING_JSON_SPEC` / 考试与风格 JSON 契约逐字节锁定;builder 函数名与签名不变;`[unleserlich]` 占位符保留;注入顺序与空注入恒等;渲染器/解析器/路由/前端/数据库零改动;
- 行为默认不变:md 报告仍由后端渲染;mock 样例与解析容错路径不依赖提示词文本。

## 八、OCR 契约 v2 与标记体系(2026-09-18)

- 契约升级:OCR JSON 五字段(+ecognition_quality / quality_note;旧任务与解析零破坏);uild_grading_user_message(quality=None) 默认输出逐字节不变;
- 零修正红线:【本模式规则】禁止清单+反例锚定(ich findet);【输出前自检】逐句反查+修正痕迹扫描;
- 标记体系(扩展不替代):[unleserlich]/[unleserlich×n] 保留;[unsicher:猜测文本] 新增二级(低把握猜测);评分侧两档均不据此新增错误条目;
- 展示:TranscriptPanel.renderWithMarkers(红=无法辨认/黄=低把握)+ ReviewPage 复核区低质量 Alert。

## 九、管线 A 复核态提示词口径(2026-09-20)

- 关闭复核(默认):A 使用「管线 A 综合批改」提示词,单次执行图→全字段;
- 开启复核:阶段1 复用「管线 B 识别」OCR 角色提示词(附录取 ocr 位),阶段2 复用「管线 B 评分」角色提示词(附录取 grading 位,风格注入一致)——两管线提示词完全同源,仅调用端点不同。
