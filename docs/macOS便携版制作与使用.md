# macOS 便携版 · 制作与使用指南

> 适用:Apple 芯片(M 系列)与 Intel 芯片 Mac;与 Windows 版**同一代码库、同一界面、同一数据格式**。

## 一、它是什么

与 Windows 版完全对等:内置便携 Python 运行时(`runtime/python`)、前端已构建产物(`frontend/dist`)、双击脚本即用、**制作完成后全程离线**(除云端模型调用外)。业务功能逐一一致:批改/审阅、台账/考试/统计、设置中心、数据加密与解锁、OCR 异常检测自愈、PDF 上传、练习卷生成、图片存档压缩等。

## 二、制作(每台 Mac 首次,需联网一次)

1. 把整个项目文件夹拷到 Mac(如 `/Users/你的用户名/批改器`;U 盘拷贝无"下载隔离"问题);
2. 首次使用前,给系统安装免费的命令行工具(仅当系统未自带 python3 时):
   终端执行 `xcode-select --install`;
3. 双击「**首次制作mac运行环境.command**」:
   - 自动识别芯片架构(Apple 芯片 arm64 / Intel x86_64)并下载对应便携运行时;
   - 自动安装全部依赖、校验并授权所有 `.command` 脚本、运行一键自检;
   - 若曾从 Windows 目录整体拷来旧 runtime,制作器会自动把它备份为 `runtime/python.bak-*`,确认启动正常后可手动删除;
4. 完成后双击「**一键启动.command**」→ 浏览器自动打开(端口 8765,被占用自动切换 8766);结束用「**一键停止.command**」。

### Gatekeeper(首次运行提示"无法验证开发者")

- 首选:右键「首次制作mac运行环境.command」→ **打开** → 在弹窗中再点"打开"(仅需一次);
- 或终端执行:`xattr -dr com.apple.quarantine /路径/批改器`(制作器也会自动尝试清理);
- 本项目为命令行脚本 + 便携二进制,**无需签名与公证**;经 U 盘拷贝通常不会带隔离属性。

## 三、分发(推荐给其他 Mac)

在一台 Mac 上完成制作后,把**整个文件夹**打包 zip 分发(约 350–400MB):其他 Mac 解压即用、全程离线,无需再执行制作器。

- **Apple 芯片与 Intel 各打包一次**:便携运行时按架构区分;同一台 Mac 只能运行对应架构的包(Apple 芯片可用 Rosetta 运行 Intel 包,但不推荐,建议直接用对应架构包);
- 分发前建议在「设置中心 → 数据加密」确认本机数据已按需加密;班级数据包(`class_package_*.zip`)跨平台互导即可迁移数据。

## 四、与 Windows 版的数据兼容(已验证设计)

| 对象 | 兼容性 |
|---|---|
| 班级数据包(zip) | 纯 JSON + 图片,Win ⇄ Mac 双向导入/导出,零转换(文件名兼容 GBK/UTF-8) |
| 数据库文件 | SQLite 单文件跨平台;迁移脚本(Alembic)随代码一致,自动升级 |
| 上传图片/报告 | 标准 JPEG/PNG/WebP/PDF 中间产物,无平台依赖 |

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 双击脚本提示"没有可用的运行环境" | 先运行「首次制作mac运行环境.command」(需联网) |
| 浏览器没自动弹出 | 手动访问窗口里显示的地址(默认 `http://127.0.0.1:8765`) |
| 端口被占用 | 启动脚本自动改用 8766;两个都被占用时按提示先关闭占用程序或先「一键停止」 |
| 依赖安装失败 | 检查网络后重新双击制作器(已下载的运行时会被复用/覆盖,不会损坏数据) |
| 想卸载 | 直接用「一键停止」后删除文件夹即可;数据都在文件夹内部(`backend/data`) |

## 六、验收清单(建议在一台 Mac 上走一遍)

1. 制作器 → 一键自检全 OK;
2. 一键启动 → 浏览器打开 → 完成一次批改(云端管线);
3. 上传一张扫描 PDF(逐页展开)、导出成绩表;
4. 设置中心保存一次配置;若启用加密,则验证"选择班级数据 → 解锁 → 进入";
5. 「一键停止」后再次启动,数据仍在;
6. 从 Windows 版导出班级数据包 → Mac 导入;Mac 导出 → Windows 导入(双向)。
