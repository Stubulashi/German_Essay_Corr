## 0. 报错原文(保持原样)

```
批改失败:目标端点/模型疑似不支持图片输入:模型回复中出现“未收到任何图片”。请改用支持视觉的模型(如 qwen-vl-plus / qwen2.5-vl),或为识别配置独立视觉端点;当前端点:http://10.30.13.1:8288/v1 / Qwen3.8-27B-Q4_K_M
```

- 该报错由本系统 `backend/app/services/ocr_anomaly.py::raise_if_vision_failed()` 在识别到模型自述“未见图片”时抛出;
- 端点信息:`http://10.30.13.1:8288/v1` / `Qwen3.8-27B-Q4_K_M`(保持不变)。

## 1. 结论摘要

**根因判定:端点侧(服务端)不实现图片输入 —— 网关的聊天链路在把请求送进模型之前就丢弃了全部图片内容,任何客户端载荷调整都无法送达模型。**

量化依据:该端点带图请求的 `prompt_tokens` 与同提示词的**纯文本请求完全一致**(带 313KB 图片的请求仅计 14~20 tokens,图片零 token 贡献),且模型回复原文自述“没有附带任何图片”。

排除结论:图片**已正确送达**该端点(HTTP 200、体积 313KB/627KB 均被接收、连接与鉴权正常),**不是**“未送达 / 被截断 / 格式不接受 / 载荷结构不接受”类客户端问题。

对照组(同一张图、同一份载荷,发往阿里云 MaaS 工作区):`qwen3-vl-plus` 的 `prompt_tokens=2502` 并成功转录出手写德语原文 —— 证明本系统发送的 JPG data URL 载荷、图片归一化护栏(**1350×2400 JPEG,data:image/jpeg;base64 前缀**)完全正确。

## 4. prompt_tokens 对照矩阵(两轮共 13 种载荷形态 × 4 个模型)

**判读方法**:`prompt_tokens` 是服务端实际送入模型的输入计量。若图片真被模型接收,视觉编码会显著增加 token(见第 6 节对照组:同一图 ≈2,500 tokens)。本端点带图请求与纯文本基线**同值**,说明图片在进入模型前已被丢弃。

| 载荷形态 | HTTP | prompt_tokens | 模型回复关键内容 |
|---|---|---|---|
| jpg data URL(线上形态) | 200 | **14** | `content:"未检测到图片，请上传图片。"`;思考段:`"I don't see any image attached to this message...there's no image provided in this conversation."` |

## 7. 判定与排除项

| 可能原因 | 排查动作 | 实测结果 | 判定 |
|---|---|---|---|
| 网络不可达 / 超时 | 多次请求、含流式 | 全部 HTTP 200,SSE 正常 | 排除 |
| 鉴权失败 | 文本请求 | 正常返回 | 排除 |
| 图片格式不被接受 | jpg / png / 裸 base64 / 公网 URL | 全部被丢弃 | 排除 |
| 载荷结构不被接受 | 标准 OpenAI / 扁平 / 字符串 / Responses 风格 / Ollama 风格 / 图片前置 / 双图 | 全部被丢弃 | 排除 |
| 体积超限被截断 | 单图 313KB、双图 627KB | 均 HTTP 200,无 413 | 排除 |
| 图片未送达(客户端未发) | 第 5 节载荷结构 + 服务端正常响应文本 | 已送达但被服务端丢弃 | 排除 |
| **端点/网关不实现图片输入** | 第 3、4 节(实现证据 + 13 色矩阵) | **成立** | **根因** |

次生发现(仅记录,本次不修改):`backend/.env` 中 `OCR_MODEL=qwen2.5-vl` 在阿里云 MaaS 工作区不存在(`model_not_found`);该工作区实际提供 `qwen3-vl-plus` / `qwen-vl-ocr` / `qwen3-vl-flash` / `qwen-vl-max` 等视觉模型(模型列表共 256 项,已实测 `qwen3-vl-plus` 可用)。

## 9. 边界说明与改进参考(非本次执行项)

1. **该网关并非“完全不支持图片”**:其视频生成管线 `/api/generate`(multipart 表单)支持 `images` 参考图输入;但**聊天链路**(`/v1/chat/completions` 兼容层、原生 `/api/chat`、自研 `/chat` 页面)从实现上不支持图片输入(见 3.2~3.5)。

3. **已有可用替代通道(仅记录,本次未使用)**:阿里云 MaaS 工作区视觉模型(如 `qwen3-vl-plus`)已实测可正常接收本系统的 JPG data URL 载荷并完成手写转录(见第 6 节)。
4. 本报告未改动任何代码、`.env`、设置中心配置或运行状态;文件本身为唯一新增产物。
